# Tsabit Mumtaz — Portfolio

Personal portfolio website for Tsabit Abdurrazzaq Mumtaz.

## Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Structure

```
portfolio/
├── index.html       — Main page
├── script.js        — Interactions (scroll reveal, nav, menu)
├── assets/
│   └── images/      — Project screenshots (replace placeholders)
└── README.md
```

## Getting Started

Open `index.html` in a browser. No build step required.

To replace project placeholders, add screenshots to `assets/images/` and update the `<div class="placeholder-img">` elements in `index.html` with `<img>` tags.

## Customization

- **Colors**: Edit the Tailwind config in `index.html` `<script>` tag
- **Fonts**: Swap Google Fonts links and update `fontFamily` in Tailwind config
- **Content**: Edit HTML directly — all text is inline
- **Links**: Update social/email links with real URLs
